# Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five guided lessons on the real board, each step a spotlight on one control with a short instruction, with the board locked so only the highlighted control works.

**Architecture:** A lesson is data (a state recipe plus ordered steps). A root `TutorialService` runs it on the real `GameBoard` through `GameService`, which gets an off-by-default hook for allowed actions and scripted bot moves. A spotlight overlay finds board elements by a `data-tutorial` anchor id. The engine and content projects are untouched.

**Tech Stack:** Angular (standalone components, signals), Angular Material and CDK, Jest, the existing `engine`, `content` and `bots` projects.

**Spec:** `docs/superpowers/specs/2026-11-25-tutorial-design.md`

## Global Constraints

- **Layering:** Nothing changes in `projects/engine` or `projects/content`. The UI never decides legality: A scripted bot picks only from `getLegalActions`, and the action gate only refuses, never invents.
- **No dev code in production:** Nothing under `projects/app/src/app/dev/` is imported by the Tutorial. Task 1 moves the shared helpers out of `dev/`.
- **Routes:** `/tutorial` is lazy and behind `offlineOnly`. `/game`, Setup and the `Layout` service are not changed.
- **UI text style (CLAUDE.md):** Instructions are sentences in sentence case with keywords capitalised ("Click Sha to attack Seat 1"). Buttons and titles are Title Case ("Next", "Exit Tutorial", "Start Lesson"). Vietnamese is sentence case everywhere and starts as a draft. Ids are never shown ("Seat 0", not `seat-0`).
- **Catalog keys:** Every visible string is a `tutorial.*` key in both `i18n/en.ts` and `i18n/vi.ts` (`Messages` requires every English key in Vietnamese).
- **Docs style (CLAUDE.md):** Bullets over long paragraphs, bold key terms, every sentence, heading, list item and table cell starts with a capital letter, including after a colon.
- **Git:** Work on branch `feature/tutorial`. Never push, never merge. End every commit message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- **Commands:** One spec file: `npx jest <path>`. Before finishing: `npm run verify`, `npm test`, `npm run i18n:status`.

## Review Focus

- **Beginner leaves mid-lesson (route change, browser Back):** The Tutorial game is discarded, the hooks are cleared, and `/play` does not offer it as a game in progress. Pinned in Task 3 and Task 10.
- **Beginner clicks outside the hole or presses a key for another control:** Nothing changes. Pinned in Task 3 (gate) and Task 6 (overlay).
- **Window is resized or the phone rotates mid-step:** The spotlight follows its target, or the step shows without a hole if the target is not on screen. Pinned in Task 6.
- **Target missing on this layout (a phone-only difference):** The step falls back to its text card, and Next or Exit still work, so the beginner is never stuck. Pinned in Task 6 and Task 8.
- **`localStorage` throws or is empty (private window):** The page still works and shows no lessons done. Pinned in Task 4.
